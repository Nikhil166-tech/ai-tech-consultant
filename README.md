# AI Tech Consultant

Autonomous AI Tech Consultant system for tech consultancies. Built for the Business Labs hiring capstone.

## Project Structure
- `task-1-knowledge-brain/`: Self-evolving product memory, polite crawler, multimodal vision, and citation-grounded RAG API (Python).
- `task-2-inbox-agent/`: Autonomous inbox triage and HITL 20-streak auto-send agent (TypeScript).
- `task-3-meeting-sow/`: Multi-agent pipeline converting meeting transcripts into SOW, dev estimates, and change orders (Python).
